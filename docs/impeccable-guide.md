# 🎨 Impeccable — คู่มือเลือกคำสั่ง

สกิลออกแบบ Frontend/UI จาก [pbakaus/impeccable](https://github.com/pbakaus/impeccable) (v4.5) ติดตั้งแบบ global ไว้ที่ `~/.claude/skills/impeccable`
เอกสารฉบับเต็ม: https://impeccable.style/docs/

รูปแบบคำสั่ง: `/impeccable <คำสั่ง> <สิ่งที่จะทำ>`

> ใช้กับงานหน้าบ้าน (เว็บ, แลนดิ้งเพจ, แดชบอร์ด, ฟอร์ม, คอมโพเนนต์) เท่านั้น ไม่ใช้กับงาน backend

---

## 🔧 ตั้งค่า

| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `init` | ทำครั้งแรกในแต่ละโปรเจกต์ สร้าง PRODUCT.md เก็บข้อมูลโปรดักต์และแนวดีไซน์ |
| `document` | โปรเจกต์มีหน้าเว็บอยู่แล้ว ให้อ่านสไตล์จากโค้ดไปเขียนเป็น DESIGN.md |
| `hooks on` / `off` / `status` | เปิด ปิด หรือดูสถานะการตรวจดีไซน์อัตโนมัติหลังแก้ไฟล์ UI |
| `doctor` | การตั้งค่าดูแปลกหรือเก่าไป ให้ตรวจและซ่อม |

## ✨ สร้างของใหม่

| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `/impeccable ออกแบบหน้า...` | บอกตรงๆ ว่าอยากได้อะไร |
| `shape` | วางแผน UX/UI ให้ชัดก่อนเริ่มเขียนโค้ด |

## 🔍 ตรวจหน้าที่มีอยู่

| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `critique` | อยากรู้ว่าดีไซน์ยังขาดอะไร ให้คะแนนและบอกว่าควรแก้อะไรก่อน |
| `audit` | ตรวจปัญหาทางเทคนิค เช่น accessibility, ความเร็ว, responsive |

## 🎨 ปรับหน้าตาตามอาการ

| อาการ | คำสั่ง |
|---|---|
| จืด ดูธรรมดาเกินไป | `bolder`, `colorize`, `delight` |
| อยากได้ระดับ "ว้าว" | `overdrive` |
| ฉูดฉาด รกตา | `quieter` |
| ของเยอะจนหาอะไรไม่เจอ | `distill` |
| ระยะห่างไม่สวย ไม่รู้จะมองตรงไหนก่อน | `layout` |
| ตัวหนังสืออ่านยาก ฟอนต์ไม่เข้ากัน | `typeset` |
| ข้อความ ปุ่ม หรือ error เข้าใจยาก | `clarify` |
| หน้าพังบนมือถือ | `adapt` |
| เว็บช้า | `optimize` |
| อยากมี animation | `animate` |

## 🚀 ก่อนปล่อยใช้งานจริง

| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `harden` | ให้หน้ายังใช้งานได้ตอนเกิด error, ข้อมูลว่าง, เน็ตหลุด หรือรองรับหลายภาษา |
| `onboard` | ออกแบบหน้าที่ผู้ใช้ใหม่เห็นครั้งแรก และหน้าที่ยังไม่มีข้อมูล |
| `polish` | เก็บรายละเอียดรอบสุดท้ายก่อนส่งงาน |
| `extract` | ดึง UI ที่ใช้ซ้ำหลายที่ออกมาเป็นคอมโพเนนต์และ token กลาง |

## 🖱️ ลองหลายแบบในเบราว์เซอร์

ใช้ได้กับเว็บเท่านั้น และต้องรัน dev server ไว้ก่อน

| คำสั่ง | ใช้ตอนไหน |
|---|---|
| `live` | คลิกเลือกส่วนบนหน้าเว็บ แล้วให้ทำหลายเวอร์ชันมาให้เลือก |
| `generate 3 ปุ่มสมัคร` | ทำมาหลายแบบแล้วเลือกแบบที่ชอบ |

---

## 🗺️ ลำดับการใช้งานที่แนะนำ

```
init → document หรือ shape → สร้างหน้า → critique → แก้ตามอาการ → audit → polish
```

💡 ไม่รู้จะใช้คำสั่งไหน พิมพ์ `/impeccable` เฉยๆ มันจะดูสภาพโปรเจกต์แล้วแนะนำ 2-3 คำสั่งที่ควรทำต่อ
